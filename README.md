# 👶 宝宝成长工作台

1-3 岁学步期宝宝的学习成长 PWA 应用。手机、电脑浏览器打开即可**一键安装到桌面**，离线可用。

## ✨ 功能

- **👶 宝宝档案**：头像、生日，自动计算月龄
- **🎓 闪卡启蒙**：动物/食物/身体/颜色/形状/家庭/数字/汉字 8 大分类，140+ 卡片，全 emoji 渲染 + 中文发声（Web Speech API）
- **🎵 儿歌小屋**：10 首经典童谣，TTS 逐句跟读
- **📈 成长记录**：发育里程碑（12-36 个月）勾选记录
- **🏅 打卡激励**：每日三任务 + 星星 + 勋章墙
- **📊 本周周报**：学习天数 / 新认识卡片 / 分类增量 / 每日足迹
- **🔒 宝宝模式**：全屏沉浸 + 误触锁定，家长模式管数据
- **💾 纯本地存储**：localStorage，数据导出 JSON 备份

## 🚀 使用

| 平台 | 安装方式 |
|---|---|
| 电脑 Chrome/Edge | 打开网址 → 地址栏「安装」图标 |
| iPhone Safari | 分享 → 添加到主屏幕 |
| Android Chrome | 菜单 → 添加到主屏幕 / 安装应用 |

离线可用：Service Worker 全量缓存，无网络也能用。

## 🛠 技术栈

纯静态前端：HTML + CSS + JS（零依赖、零框架）+ PWA（manifest + Service Worker）。无服务器、无数据库、无构建步骤，克隆即用。

## 📂 结构

```
├── index.html          # 页面结构
├── css/style.css       # 马卡龙配色样式
├── js/data.js          # 内容库（闪卡/儿歌/里程碑）
├── js/app.js           # 业务逻辑
├── manifest.json       # PWA 清单
├── sw.js               # Service Worker
├── icons/              # 应用图标
└── generate_icons.py   # 图标生成脚本
```
